# Banglore-House-Price-Prediction

This project aims to predict house prices in Bangalore using Python. It involves Exploratory Data Analysis (EDA), data preprocessing, feature engineering, and training a Linear Regression model to estimate property prices. The final model achieves an accuracy of 78%, providing reliable price predictions based on key features.

📌 Key Highlights
📊 EDA performed using pandas, matplotlib, and seaborn to understand data patterns, distributions, and outliers.

🛠️ Data cleaning and feature engineering to handle inconsistencies like location grouping, outlier removal, and dimensionality reduction.

🧠 Built a Linear Regression model with optimized input features.

✅ Achieved ~78% model accuracy, evaluated using R² Score and residual analysis.

📈 Visualizations to demonstrate relationships between price, location, size, and other variables.

💡 Code modularized for flexibility in applying different models later.

📂 Technologies Used
Python (Pandas, NumPy, Matplotlib, Seaborn)

Scikit-learn (Linear Regression, model evaluation tools)

Jupyter Notebook
